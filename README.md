# 📱 reo Mobile (iOS Client & IPA Builder)

Мобильное приложение **reo Music** для iPhone и iPad:
* Адаптивный мобильный интерфейс с поддержкой Safe Area (Notch / Dynamic Island).
* Фоновое воспроизведение музыки при заблокированном экране iOS.
* Поддержка управления с экрана блокировки и Пункта управления (Control Center) через Apple MediaSession.
* Синхронизированное построчное караоке (LRCLIB + Genius) с возможностью ручной привязки текстов для ремиксов.
* Подключение к вашему серверу **reo backend** через ввод IP/URL в настройках.

## 🛠️ Как получить файл `.ipa` через GitHub Actions (без компьютера Mac)

В папке уже настроен готовый сценарий автосборки в виртуальной среде Apple macOS от GitHub.

### Шаг 1. Загрузка репозитория на GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com/new) (можно приватный или публичный), например `reo-mobile`.
2. Загрузите в него содержимое папки `reo mobile`:
   ```bash
   cd "reo mobile"
   git init
   git add .
   git commit -m "Initial commit for iOS build"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИКНЕЙМ/reo-mobile.git
   git push -u origin main
   ```

### Шаг 2. Запуск сборки .ipa
1. Откройте ваш репозиторий на GitHub в браузере.
2. Перейдите на вкладку **Actions**.
3. В левой колонке выберите воркфлоу **Build iOS IPA**.
4. Нажмите кнопку **Run workflow** справа и подтвердите запуск.

### Шаг 3. Скачивание готового файла
1. Сборка на сервере Apple macOS займет около 2-3 минут.
2. Когда появится зеленый чекбокс `✓`, нажмите на завершенный запуск.
3. В самом низу в блоке **Artifacts** нажмите на **`reo-ios-ipa`**.
4. Скачается архив, внутри которого лежит готовый файл **`reo.ipa`**!

## 📲 Установка .ipa на iPhone

Установите скачанный файл `reo.ipa` любым привычным вам способом:
* **Scarlet / ESign / GBox** — прямая установка и подпись прямо на телефоне.
* **AltStore / SideStore** — подпись через компьютер или Wi-Fi с помощью вашего Apple ID.
* **TrollStore** — если у вас установлена поддерживаемая версия iOS с TrollStore.

## 🔗 Подключение к серверу в приложении

1. Откройте установленное приложение **reo** на iPhone.
2. Перейдите во вкладку **Настройки** (шестеренка в нижнем меню).
3. В поле **Адрес бэкенд-сервера** введите адрес вашего сервера, например:
   ```
   http://192.168.1.50:8080
   ```
   или ваш домен/внешний IP:
   ```
   http://YOUR_SERVER_IP:8080
   ```
4. Нажмите **«Проверить»** — когда загорится зеленый индикатор с пингом (например, `18 ms`), поиск, караоке и стриминг треков готовы к работе!
